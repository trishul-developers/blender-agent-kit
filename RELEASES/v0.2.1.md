# Blender Agent Kit v0.2.1

Patch release — CLI correctness, repeatable review sheets, and an independently evaluated modular-kit showcase.

## Fixed

- Public `--result-json` is now owned by the host entrypoint instead of leaking into Blender's internal bootstrap result transport. `inspect`, `qa`, `pack`, `export`, `bundle`, and `review` are covered by host regression tests.
- SupplyCrate texture showcase generation now includes **all five** source PBR maps and **all four** Unity URP packed maps. The 16-bit PNG reader validates the PNG signature, supported channel/depth combinations, and unfiltered scanlines; PNG/WebP content is validated and missing inputs fail closed.
- The texture generator exposes the actual metallic/smoothness alpha channel rather than presenting RGB alone. Synthetic fixtures cover nine tiles and a 16-bit normal PNG.
- The README no longer displays the previously reported blank legacy `demo_textures.webp`. Instead, it shows a compressed preview of the original six-tile PNG supplied in the SupplyCrate archive; this is **not** represented as regenerated nine-map evidence.

## Added

- Generic, host-side `tools/review_compose.py` for configurable multiview, LOD, range, and collision contact sheets using real source images and caller-supplied evidence labels. Includes host tests and CI Pillow installation.
- A second, materially different independent-agent case study under `demos/SciFiKit/`, including source-archive assessment, machine-evidence summary, provenance limitations, and a hash-checked importer.
- Sci-Fi trial documents a 60-object / 30-mesh six-piece modular assembly, directional snap sockets, a two-material bulkhead, LOD0–3 (3,628 / 1,260 / 372 / 72 visible triangles), QA pass with explicitly unverified UV1 overlap, 5,380-triangle Blender FBX round-trip including collision, and four Unity URP packed texture slots. These figures describe **supplied original machine evidence**, not a fresh v0.2.1 rebuild.

## Evidence and limitations

- Blender 5.2 tests validate the tooling; they are **not** a fresh rerun of the supplied Sci-Fi kit or SupplyCrate full asset build.
- SupplyCrate's corrected nine-map contact sheet requires raw and packed map regeneration. No manually reconstructed sheet or invented production evidence was committed in this patch.
- Sci-Fi's original proof images and editable builder exist in the supplied archive; the repository publishes an evidence assessment, importer and two lightweight WebP previews from the original agent images, **not** a newly regenerated canonical asset gallery. The asset conversion/rebuild workflow remains follow-up work.
- Unity Editor asset import was not executed or verified.
- Independent agent-reported productivity savings are subjective feedback, **not** a measured benchmark.
