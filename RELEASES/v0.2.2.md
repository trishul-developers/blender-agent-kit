# Blender Agent Kit v0.2.2 — Candidate Notes

This is a **candidate**, not a published release. The final release tag is created only after an exact-head review and CI approval.

## Independent agent showcase

- Promotes two **newly authored** external-agent demonstrations in the README: a procedural SupplyCrate and the Helios Conduit six-module Sci-Fi kit. The new master/optimized images, scenes, sources, original machine reports, manifests, and analysis remain in `demo/`.
- SupplyCrate: 4,204 / 1,084 / 136 visible tris; 12-triangle collision; four Blender FBX round trips passed; nine-map source PBR → URP sheet includes 16-bit normal and metallic smoothness alpha evidence.
- Helios Conduit: six piece types, 21 module instances, 109 objects in the assembled scene, 2,392 / 904 / 336 / 60 visible bulkhead LOD triangles, six socket empties, three collision hulls, six Blender FBX round trips passed.
- The independent agent's **retrospectively estimated** effort savings are presented with explicit scope/methodology: **74–80% pipeline-only** and **55–63% combined end-to-end**. The estimates are not controlled benchmark results or guarantees. It reported two genuine QA-caught authoring defects, zero round-trip failures in ten exported FBXs, and particularly useful hierarchy-safe export, QA, URP packing, and review automation.
- The trial did **not** execute Unity Editor; all engine-target checks are Blender round trips, profile assertions, and texture validation.

## General-purpose toolkit improvements

- Treat recognized collision meshes as collision inventory, not render-LOD mesh/triangle/bounds contributions; carry configured LOD exclusions into review inventory.
- Validate `required_parent_pairs` structure before launching QA, including merged target overlays; enforce corresponding target schema constraints.
- Provide fast `run.py <subcommand> --help` based on the real argument declarations, without launching Blender.
- Upgrade host review compositor with readable scalable fonts, title/subtitle, non-cropped layouts, explicit 16-bit RGB/RGBA PNG channel reading, and a visible smoothness alpha split.
- Add optional source-bound Unity `_EmissionMap` packing for URP/HDRP without fabricating emission maps when no source exists.
- Surface a bounded `stderr_tail` in machine-readable errors when headless Blender fails, while still retaining the full local log.
- Improve onboarding docs with a minimal external profile and Blender executable discovery.

## Version-independent release safety

- A new **Tier-4 independent-source CI smoke** regenerates both procedural texture sets, rebuilds the SupplyCrate and representative Sci-Fi bulkhead with Blender 5.2.4, runs QA, packs URP textures (including optional emission), and verifies all 10 newly exported FBXs by Blender fresh import. This does not rerender all beauty images or exercise Unity Editor.
- Delete one-off `publish-v0.2.1.yml`.
- Add `workflow_call` to existing host/Blender CI and a version-neutral `release.yml` triggered by `v*.*.*` tags.
- Require the exact tagged SHA's Ubuntu, Windows and Blender CI jobs to pass before `gh release create`, and require matching `RELEASES/<tag>.md` notes. The release job verifies the supplied tag and SHA.

## Evidence and storage limits

- Machine results and effort figures are independently **agent-reported**; no fresh rebuild by this release author has yet been performed.
- `demo/` contains substantial historical binary evidence. This release preserves the originally delivered files and attaches a deterministic independent-trial archive plus SHA256 to the GitHub Release. Future generated binary outputs are ignored by `demo/.gitignore`, while source/configuration, JSON evidence and optimized WebP remain suitable for normal Git. Existing Git history is not rewritten, so the original 115 MB commit remains in repository history.
