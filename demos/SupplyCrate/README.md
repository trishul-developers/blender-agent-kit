# SupplyCrate — Blender Agent Kit demo

A deterministic procedural supply crate generated end-to-end through Blender Agent Kit (Blender 5.2.2 LTS, Unity target, `prop-showcase` demo profile).

This demo is intentionally non-project-specific: it shows how an agent can create geometry and textures, validate production constraints, generate LOD/collision outputs, render review evidence, and export a semantic engine bundle.

```powershell
python demos/SupplyCrate/run_demo.py          # textures → build → inspect → QA → pack → bundle → review → showcase
python demos/SupplyCrate/make_sheets.py       # regenerate showcase contact sheets only
```

Use `--blender <path>` if Blender is not discoverable automatically.

| Stage | Skill | Result |
|---|---|---|
| Procedural PBR atlas (2048², 4 quadrants: wood/steel/rope/spare) | `blender-uv-baking` raw-map contract | `base_color`, `roughness`, `metallic`, `ao`, 16-bit `normal` |
| Geometry + UV0 + lightmap UV1, LOD0/1/2 + collision | `blender-modeling`, `blender-lod-collision` | 3,136 / 1,600 / 240 tris, 12-tri collider |
| QA (`lod_prop` class) | `blender-asset-qa` | PASS, 0 errors (UV1 overlap reported as `unverified` by design) |
| Unity URP texture pack | `blender-target-unity` | albedo, metallic/smoothness, normal, AO |
| Bundle export + Blender fresh-import | `blender-bundle` | 4 FBX files, all round-trip PASS, 0 embedded images |
| Review renders (Cycles) | `blender-core review` | close-up, orthographic, LOD×distance, collision review |

| Part | Tris |

`evidence/summary.json` is a compact checked-in record of the demonstrated run. A fresh run writes the full path-normalized machine JSON under the ignored `evidence/generated/` directory. `showcase/` contains lightweight WebP images used by the repository README. The `demo_textures_historical.webp` image is a compressed preview of the six-tile original source ZIP PNG, not a regenerated nine-map output. A fresh nine-map source-to-URP showcase remains follow-up work. Raw textures, packed textures, FBX files, the `.blend` source, and individual review PNGs are regenerated by `run_demo.py` and are intentionally not committed.

The scene includes an explicit three-point showcase light rig so the checked-in hero images remain art-directed and reproducible. Blender Agent Kit also has automatic size-scaled review lighting for scenes that do not provide lights.

The Unity step demonstrated here is **Unity-target export** (FBX conventions + URP texture packing). It does not claim a Unity Editor import verification; engine-side verification remains a separate downstream concern.
