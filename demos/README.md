# Historical v0.2.1 demo lineage

This `demos/` directory is preserved for **v0.2.1 provenance and compatibility**. It contains the earlier SupplyCrate/Sci-Fi showcase/prototype lineage that motivated issue #4.

It is **not the canonical reproduction path as of v0.2.3**.

Use the independently authored, source-bound canonical demonstrations instead:

- [Canonical SupplyCrate](../demo/SupplyCrate/README.md)
- [Canonical Helios Conduit / SciFiKit](../demo/SciFiKit/README.md)
- [Canonical demo overview](../demo/README.md)

The canonical `demo/` lineage has:
- deterministic source texture generators and Blender builders;
- preserved original independent-trial evidence;
- current-toolkit Tier-4 source rebuilds;
- machine-readable QA/packing/export evidence;
- verified Blender FBX round trips;
- current full/smoke `run_demo.py` entrypoints.

These historical files remain intentionally unchanged where possible so old release links and provenance are not destroyed.
